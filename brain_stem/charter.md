--------------------------------------------------------------------------------

physical environments based on real-time task complexity and hardware weight limits:

- Hosts the 400MB World Model Core Switchboard (Block 0) pinned permanently inside
  execution memory cache. It handles zero text generation or coding tasks. Its entire
  neural footprint is dedicated to goal decomposition, token budgeting, and task routing.
- Coordinates hardware-level local execution (such as managing your local folder
  tracks and writing zero-COM document blocks cleanly to disk sectors via the
  Document Operations Authority - FB-038).

SURFACE B: The User's Mobile Phone (The Ambient Edge)
- Hosts an independent, hardware-quantized Edge-Native Micro-SLM (<1.5B parameters)
  running natively inside the smartphone's physical Neural Processing Unit (NPU).
- It stays synchronized with the laptop core by silently ingesting highly compressed
  binary Teacher-Student LoRA patches streamed across encrypted network sockets,
  inheriting capabilities with zero on-device training overhead or battery drain.

SURFACE C: The Private Cloud Cluster (The High-Entropy Thinker)
- Wakes up asynchronously ONLY when the local core flags a task graph as a high-complexity,
  long-horizon strategic reasoning problem (e.g., compiling a massive multi-file
  codebase) that exceeds local VRAM capacity.
- The local core packages the context payload, passes the cryptographic security keys,
  and proxies the calculation to an external multi-billion parameter cluster node
  without stalling local user interface response speeds.
